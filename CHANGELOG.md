# Changelog

## 2.3.1
- New flat app icon.
- Translated READMEs (8 languages), screenshots, issue templates.

## 2.3.0
- Detailed 3D controller rendered with OpenGL (software fallback).

## 2.2.1
- Touchpad: L3 / R3 place a finger on the left / right side and click; both = two fingers + click.

## 2.2.0
- Live 3D controller that follows the gyro.
- Two-finger touchpad gestures: sticks as fingers, D-pad swipes.

## 2.1.0
- System tray, start with the system, gyro-driven touchpad swipe.

## 2.0.0
- Qt interface with Windows 11 Mica, 7 languages, Linux version, priority over Steam.

## 1.x
- First versions: Xbox 360 and DualShock 4 emulation with gyro and rumble.
